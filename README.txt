PREVIEW THE WEBSITE
1. Extract PersonalPage.zip.
2. Open the PersonalPage folder in Visual Studio Code or another editor.
3. Open index.html in a browser, or use a local development server.
4. Test all six navigation links and resize the browser to test mobile layout.

BEFORE SUBMISSION — IMPORTANT
1. Replace images/profile-placeholder.svg with a photo you are allowed to publish. If you rename the image, update its src in index.html and biodata.html.
2. Edit the sample timetable in timetable.html to match your actual schedule. Current entries are examples only.
3. Replace portfolio descriptions/placeholders with real projects, screenshots, links and accurate descriptions. Do not claim achievements or work you have not completed.
4. Add a real playable video to video.html. The placeholder alone does not fulfil the video requirement.
   For a local MP4, put your file at videos/my-video.mp4 and replace the <div class="video-placeholder">...</div> in video.html with:
   <video controls playsinline preload="metadata" style="width:100%;border-radius:15px">
     <source src="videos/my-video.mp4" type="video/mp4">
     Your browser does not support HTML video.
   </video>
5. Replace placeholder social links in comments.html with your real public profile URLs, or remove them.
6. The feedback form validates fields in the browser only. It does NOT email, send, or store submissions. A working online form needs a backend or a form service.
7. Test all pages, images, links, form validation and video playback on desktop and mobile.
8. If your lecturer specifically means Adobe Flash, ask whether CSS/JavaScript animation is acceptable. Adobe Flash Player is discontinued; this project uses modern CSS and JavaScript animations.

FREE HOSTING OPTION: GITHUB PAGES
1. Sign in to GitHub and create a new public repository, e.g. personal-page.
2. Upload the contents of this folder (five HTML files and the css, js, images folders, plus videos if used) into the repository root. Make sure index.html is in the root.
3. Open repository Settings → Pages.
4. Under Build and deployment, choose deploy from a branch, select the main branch and root folder, then save.
5. Wait for GitHub Pages to display the published website URL. Open it in a private/incognito browser window to test it.
6. When you update the website, upload/commit changes and allow Pages to redeploy.
7. Check current GitHub Pages limits before uploading large video files; consider using an embedded video hosted on a video platform if suitable.
